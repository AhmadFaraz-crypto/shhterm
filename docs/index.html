Why shhterm

Small, honest, and private by design.

🔒

End-to-end encrypted

Messages are encrypted with AES-256-GCM. The server routes only ciphertext — it can't read your messages.

🔑

No accounts

No signup, email, or passwords. A 256-bit room key is the only credential — share it and chat.

💻

Great terminal UI

Colored names, timestamps, typing indicators, delivery marks, and switchable color themes.

🌐

Works in the browser

A web client runs on any phone or desktop — including iPhone — sharing rooms and encryption with terminal users.

🏢

Self-hostable

Run it on a cheap VPS, or a LAN-only server for same-network chat with no internet at all.

🧪

Tested & open source

Unit tests, real-TLS end-to-end tests, and C++↔browser crypto interop checks. MIT licensed.

Quick start

Build from source on macOS or Linux.

1. Install dependencies

# macOS
brew install cmake ninja boost openssl@3

# Ubuntu / Debian
sudo apt-get install -y build-essential cmake ninja-build libboost-dev libssl-dev git

2. Clone & build

git clone https://github.com/AhmadFaraz-crypto/shhterm && cd shhterm
cmake -S . -B build -G Ninja
cmake --build build

3. Create a room (see the README for certificate setup)

./build/shhterm create --name Ahmad
# share the room key; a friend runs:
./build/shhterm join <room-key> --name Ali

Full build, deployment (VPS + Let's Encrypt), Android/Termux, LAN mode, and the web client are documented in the README.

Security model

Honest about what it protects — and what it doesn't.

✅ Protected

Message bodies are end-to-end encrypted (AES-256-GCM; key from the room-key's secret half, which never reaches the server). Transport is TLS; nothing is persisted or logged.

⚠️ Not hidden

Metadata the server must act on — usernames, room membership, message size/timing — is visible to the server. E2E protects contents, not metadata.

🔑 The key is everything

Anyone with the full room key can join and decrypt. Share it over a channel you trust. One key per room; no rotation.

📖 Be reasonable

This is a hobby/educational project without a formal audit. Great for private chats; don't use it for high-stakes confidentiality.
